# Mapa Estratégico da Indústria da Paraíba (2025–2032)

Aplicação web desenvolvida para apresentar de forma visual e interativa o **Mapa Estratégico da Indústria da Paraíba**, baseado na agenda de competitividade industrial da CNI e da FIEP/PB.

O projeto organiza os fatores estratégicos da indústria em uma experiência moderna, responsiva e dinâmica, permitindo navegação intuitiva entre eixos, princípios, objetivos e indicadores apresentados no documento oficial.

---

## Sobre o Projeto

O sistema apresenta os principais fatores estratégicos para o desenvolvimento da indústria paraibana até 2032, organizados em uma estrutura visual inspirada em uma mandala estratégica.

Entre os conteúdos apresentados estão:

- Ambiente de Negócios
- Ambiente Econômico
- Baixo Carbono e Recursos Naturais
- Comércio e Integração Internacional
- Desenvolvimento Humano e Trabalho
- Desenvolvimento Produtivo, Tecnologia e Inovação
- Educação
- Infraestrutura

A aplicação também possui:

- Visualização gráfica em formato de mandala
- Roadmap infográfico interativo
- Navegação responsiva
- Sessões institucionais e estratégicas
- Componentes visuais modernos
- Interface adaptada para desktop e mobile

---

## Tecnologias Utilizadas

- TypeScript
- React
- Vite
- Tailwind CSS
- Lucide React

---

## Funcionalidades

- Interface responsiva
- Menu interativo para navegação entre seções
- Gráfico visual em formato de mandala estratégica
- Componente de roadmap infográfico
- Navegação suave entre seções
- Layout moderno com efeitos visuais e blur
- Integração com links externos

---

## Objetivo

O projeto tem como objetivo transformar o conteúdo estratégico do documento oficial da indústria da Paraíba em uma plataforma digital acessível, visual e interativa, facilitando a compreensão dos fatores de competitividade e desenvolvimento industrial para os próximos anos.
